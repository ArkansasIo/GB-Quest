# Full class and race UI redesign

## Design contract

This is an additive presentation layer for the existing 160×144 GB-Quest interface. It derives identity from the active character or character-creation draft. It does not replace gameplay scenes, rules, save formats, input bindings, or menu routing.

## Covered interface surfaces

The shared identity layer is applied to existing framed UI components and shared headers, so class and race accents carry through title/character creation panels, field HUD, player and party identity, minimap and hotbar frames, start menu, character sheet, equipment, inventory, bank, wardrobe, spellbook, combat arts, skills, talents, quest log, world map, bestiary, activity finder, social panels, crafting, auction house, shops, guild, settings, dialogue and pop-up windows. Specialised pages retain their existing layouts and actions; this is a shared visual system, not a claim that every page has been rebuilt from scratch.

## Rendering and accessibility

- Native pixel-grid rendering; no blur, fractional scaling, or external font dependency.
- Existing monochrome palettes bypass the added RGB accents.
- Existing UI themes remain available.
- Future classes fall back to role colours; future races use a neutral heritage accent.
- Added visuals are decorative and do not capture input or alter focus.

## Build

The new src/ui_classrace.js module loads after src/ui_mmo.js. Run:

```bash
node tools/build.cjs
npm test
```

Generated index.html and dist files should be regenerated by the build pipeline, not edited manually.
