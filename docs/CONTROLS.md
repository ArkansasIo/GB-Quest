# Controls

| Button | Keyboard | Touch | In the field | In menus | In battle |
|---|---|---|---|---|---|
| D-pad | Arrows / WASD | d-pad | walk | move cursor (hold to repeat) | choose action / target |
| A | Z / J / Space | A | talk, open, interact | confirm | confirm |
| B | X / K / Esc / Backspace | B | mount or dismount | back | back |
| START | Enter | START | main menu | — (world map: legend) | — |
| SELECT | Shift / Tab | SELECT | world map | switch tab (sound test) | toggle auto-battle |

## Extra keys (keyboard)

| Key | Action |
|---|---|
| M | open or close the **Atlas of Dunia** |
| F | full screen (full-screen build) |
| C | chat overlay (full-screen build) |
| F3 or ` | profiler overlay (64-bit video mode) |
| F9 | debug panel |

## World map

| Input | Action |
|---|---|
| D-pad | move between zones |
| A | zoom in (overview → detail → zone tiles); at zone level, travel if a waypoint is attuned |
| B / SELECT | zoom out, then close |
| START | legend |

## Atlas

| Input | Action |
|---|---|
| Drag / wheel / pinch | pan and zoom |
| + − ⌂ (or + − keys, arrow keys) | zoom, reset, pan |
| Click a zone | details: level, biome, roads, instances, bosses, quests, story |
| ROUTE FROM HERE → ROUTE TO HERE | shortest road and sea path |
| SHOW ON GAME MAP | (in game) jump the world map to that zone |
| Esc | close details, then return to the game |

Settings include **SWAP A/B** for players who prefer the other layout.
