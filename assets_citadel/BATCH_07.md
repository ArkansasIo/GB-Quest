# Batch 07 — Terrain material concepts

Eight seamless SVG material concepts: Elderwood Grass, Old Road Dirt, Castle Flagstone, Frostfall Snow, Sunscorch Sand, Cinderfield Basalt, Mirefen Peat, Aether Crystal.

Each uses a 512×512 repeating design. They are vector material concepts, not final PBR texture sets (base color, normal, roughness, AO, displacement). Runtime loader exposes them in `window.GBQ_CITADEL_TERRAIN`.
