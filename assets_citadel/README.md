# CITADEL Original Asset Library — Batch 01

This directory is the new high-resolution art source. It is separate from the legacy pixel-art assets and the old HD64 upscale atlases.

## Included in batch 01
- `assets_citadel/ui/citadel_crest.svg`: original fantasy heraldic crest for title screens, launcher identity and loading screens.
- `assets_citadel/ui/citadel_ornaments.svg`: scalable UI frame, divider, slot, crest, gem, star and orb ornament primitives.
- `assets_citadel/manifest.json`: stable IDs, family targets, quality requirements and provenance.

## Asset policy
- Do not use nearest-neighbour enlargement as a substitute for redesign.
- Preserve legacy source assets in place; never bulk-delete the old art.
- New assets must be original, consistent in material language, colour grade, lighting and silhouette.
- Keep source masters and optimized runtime derivatives separate.
- Raster production targets: 4K environments, 2K character/creature masters, 1K item renders and 512px UI icons.
- Vector UI assets must use scalable SVG and remain crisp at device scale.
- Every production asset requires a stable ID, source dimensions, licence/provenance, family, variants, alpha policy and integration status.
