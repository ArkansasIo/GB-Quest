# Batch 02 — race portraits and class insignia

## Added race portrait masters
Human, High Elf, Stone Dwarf, Orc, Tiefling, Dragonkin, Beastkin and Returned (undead).

## Added class insignia masters
Warrior, Paladin, Mage, Ranger, Rogue, Cleric, Necromancer, Summoner, Berserker, Alchemist, Artificer and Bard.

## Format and use
These are scalable SVG concept masters, not finished 3D character models or rigged animation assets. Race portraits are 1024×1024 viewBox artwork; class insignia are 512×512. The source files remain editable. Rasterize only at the target display density and keep the SVG masters.

Catalog: `catalog.json`. All assets are original to GB-Quest and use the CITADEL gold/navy visual language.
